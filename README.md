# VideoLens

**记得一个场景，却想不起它在哪个视频里？** VideoLens 是一款 Windows 桌面应用，让你用一句话搜索本地视频库，并直接跳到可能相关的片段。

## 为什么做这个项目？

我电脑里存着不少视频，平时也经常翻出来看。有时候突然想起一个画面、一句台词，或者某段讲解，却想不起它出自哪个视频，更不知道在第几分钟。靠文件名搜不到，就只能一个个打开、拖进度条。

所以我做了 VideoLens：先让它分析手头的视频，再把记得的内容写成一句话。哪怕不知道文件名，也能从候选片段里找起。

## 能做什么？

- **导入本地视频**：扫描指定文件夹，按原路径建立视频库，不复制、不重命名、不修改原视频。
- **分析并建立索引**：根据已配置的模型，利用可用的文本字幕、语音转写或关键帧分析内容，生成片段摘要和标签。
- **搜索并跳转播放**：用自然语言描述你记得的内容，查看候选片段及命中的字幕或标签，也可以回看历史搜索结果。
- **导出视频片段**：选定起止时间，另存为 MP4，不影响原文件。

## 安装与使用

1. **下载安装**：在本仓库的 **Releases** 页面打开 `v1.0.0`，从 **Assets** 下载并运行 `VideoLens-Setup-1.0.0.exe`。不要下载 `Source code` 压缩包来安装。此版本的安装包未做数字签名，Windows 可能提示无法验证发布者；请仅从本仓库下载，并核对发行说明中的 SHA-256。
2. **选择工作目录**：首次打开时，按向导选择工作目录。数据库、索引和分析产物会写入这里，建议选择剩余空间充足的磁盘。工作目录不必和存放原视频的媒体目录相同。
3. **配置模型服务**：在向导中填写模型服务地址、模型名称和所需的 API Key。搜索至少需要配置 **LLM（语言模型）** 和 **Embedding（向量模型）**；需要识别视频语音时配置 **ASR**，需要分析关键帧时配置 **VLM（视觉模型）**。可以连接本地模型服务或兼容的云端 API。保存后可做连通性测试，之后也可以在「设置 → 模型服务」修改配置。
4. **导入并分析**：添加媒体文件夹后，在「视频库」点击「扫描 / 导入」，勾选视频并开启「导入后自动分析」。仅扫描目录不会自动把视频加入索引。建议第一次先选两三段熟悉的视频，可在「管理工作台 → 任务队列」查看进度。
5. **搜索片段**：分析完成后打开「智能搜索」，输入一句话，例如「讲到怎么设置白平衡的那一段」或「有人撑着伞走过站台的画面」。找到候选片段后，点「跳转播放」确认位置。后一个例子主要依赖画面信息，需配置视觉模型才更有机会找到。

## 使用须知

- **本地视频不等于全程离线**：原视频以本地路径引用。若配置了云端模型服务，搜索文本、字幕、用于转写的音频或用于分析的关键帧可能会发送到对应服务；云端调用也可能产生费用。处理敏感素材前，请确认服务商的数据政策，或改用你信任的本地模型服务。
- **搜索结果是候选，不是精确匹配**：字幕质量、语音识别效果和模型配置都会影响结果。找不到时，可以换一种描述，或先确认该视频已完成分析。
- **请尊重素材权利**：仅分析、导出和分享你有权处理的视频。导出片段不改变原素材的版权或授权条件。
